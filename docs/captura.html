Captura manual

Para sites que bloqueiam a coleta automática, como o GGMAX. Você abre a página no seu navegador e o botão salva os anúncios que estão nela.

Instalar o botão

Mostre a barra de favoritos (Ctrl+Shift+B) e arraste este botão para ela:

Salvar no comparador

No celular não dá para arrastar: use no computador.

Capturar uma categoria

  1. Abra a categoria que te interessa no site, já com os filtros e a ordenação que quiser.
  2. Clique em Salvar no comparador na barra de favoritos.
  3. Ele rola a página, passa sozinho pelas próximas páginas da categoria (até 100) e no fim baixa um único arquivo captura_….json com tudo. Clique no aviso para parar antes e salvar o que já carregou.
  4. Deixe a aba aberta enquanto ele trabalha. Uma categoria grande pode levar alguns minutos.

Levar para o comparador

No seu PC, os arquivos da pasta Downloads entram sozinhos na próxima atualização. Para entrarem na hora, rode:

.venv\Scripts\python -m scraper.main --only capturas

No GitHub, envie os arquivos para a pasta capturas do repositório.

Cada nova captura de uma página substitui a anterior dela, então anúncios que saíram somem. Capturas com mais de 7 dias deixam de aparecer; ajuste em manual_max_age_days no sites.yaml.
